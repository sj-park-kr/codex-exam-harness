# 문서 링크 정리

1. 폴더·파일 이름만 훑는다. `.git`, 의존성, 빌드 결과, 캐시, 가상환경은 제외한다. 데이터 파일은 이름만 보고 내용은 열지 않는다.
2. 루트와 모든 하위 폴더(1번 제외 대상 빼고)에 문서 유무와 관계없이 `AGENTS.md`를 만든다. 문서는 직접 들어 있는 폴더의 `AGENTS.md`에서 안내한다. 기존 `AGENTS.md`는 유지한다.
3. 각 `AGENTS.md`에 `## 문서 안내`가 없으면 만들고, 있으면 다음 동급 이상 제목 전까지의 그 구역만 갱신한다. 구역 밖의 내용과 구역 안의 기존 작업 지침은 보존하고, 문서·폴더 안내 목록만 재구성한다.
4. 각 `AGENTS.md`에 확인된 폴더 역할 한 줄을 쓰고, 문서마다 해당 `AGENTS.md` 기준 상대 경로 링크와 "언제 읽을지" 한 줄을 쓴다. `AGENTS.md` 자체는 문서 목록에 넣지 않는다. 없는 문서나 추측은 쓰지 않는다. 역할을 알 수 없으면 질문한다.
   - 문서가 아닌 데이터·제공 파일은 이름 패턴이 같은 것끼리 glob 하나로 묶고, 묶음과 단독 파일마다 용도와 언제 볼지를 한 줄로 쓴다. 이름으로 용도를 알 수 없으면 질문한다.
5. 루트에는 루트 문서와 바로 아래 폴더의 역할 한 줄, 하위 `AGENTS.md` 링크와 읽을 시점만 둔다. 각 하위 `AGENTS.md`는 바로 위 `AGENTS.md`의 안내 구역에서 링크해 더 깊은 안내도 찾아갈 수 있게 한다. 하위 문서 링크를 상위에 반복하지 않는다. 예: 루트 → `하위폴더/AGENTS.md`, `하위폴더/AGENTS.md` → 그 폴더의 문서.
6. 매번 현재 탐색 결과로 목록을 재구성해 기존의 평탄한 문서 목록도 위 규칙에 따라 재배치한다. 이동·삭제된 문서 및 하위 `AGENTS.md`의 오래된 링크와 중복 링크를 제거한다. 정렬 순서를 일정하게 유지해 재실행 시 같은 목록이 나오게 한다. 다른 지침이나 문서의 링크는 건드리지 않는다.
7. 모든 생성·유지한 안내 링크의 대상을 해당 `AGENTS.md` 위치에서 해석해 실제로 있는지, 각 glob이 파일 하나 이상에 맞는지 확인한다. 2번 대상 폴더의 `AGENTS.md` 누락, 계층별 배치, 재실행 시 중복 여부, 오래된 링크 정리와 기존 지침 보존을 검증하고, 확인 못 한 점을 보고한다.
