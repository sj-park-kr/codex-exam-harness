# 작업공간 초기화

1. 작업공간 루트에서 폴더와 파일 이름을 먼저 탐색한다. `.git`, 의존성, 빌드 결과, 캐시, 가상환경과 개인정보가 있을 수 있는 업로드·데이터 내용은 탐색 및 출력에서 제외한다. 제공 데이터 형식이 필요할 때만 민감정보를 출력하지 않도록 확인한다.
2. 기존 `AGENTS.md`와 README 및 관련 문서에서 목적과 규칙을 파악할 만큼 필요한 부분만 읽는다. 상위 지침을 따르고, 요청과 문서가 충돌하거나 문서의 역할을 판단할 수 없으면 추측하지 말고 질문한다.
3. 작업공간의 각 프로젝트 폴더에 `AGENTS.md`를 만든다. 위에서 제외한 폴더와 그 하위 폴더에는 만들지 않는다. 기존 파일은 보존하고, 생성·갱신하는 안내 구역만 수정한다. 빈 폴더도 포함하되 폴더 자체가 제외 대상인지 확인한다.
4. 각 `AGENTS.md`의 `## 문서 안내`에 해당 폴더의 문서와 작업에 관련된 상위 문서를 상대 경로 Markdown 링크로 적고, 각 링크 옆에 언제 읽을지 한 줄로 설명한다. 없는 문서나 추측한 내용을 만들지 않는다. 하위 폴더의 안내 파일도 부모의 안내에 링크해 탐색할 수 있게 한다.
5. 각 안내에 문서 생성·이동·삭제 시 관련 `AGENTS.md` 링크를 갱신하고, 코드 변경으로 기존 문서의 설명이나 사용법이 달라지면 같은 작업에서 문서를 갱신하는 규칙을 적는다. 반복 실행 시 링크와 규칙을 중복하지 않는다.
6. 링크 대상이 존재하는지, 제외한 폴더에 파일을 만들지 않았는지 확인하고 변경 사항과 확인하지 못한 점을 보고한다.
