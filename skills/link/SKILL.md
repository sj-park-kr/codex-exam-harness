# 문서 링크 정리

1. 폴더·파일 이름만 훑는다. `.git`, 의존성, 빌드 결과, 캐시, 가상환경은 제외하고, `uploads/`·데이터 폴더는 이름만 보고 내용은 열지 않는다.
2. 루트 `AGENTS.md`에 `## 문서 안내`가 없으면 만들고, 있으면 그 구역만 고친다. 나머지 내용은 건드리지 않는다.
3. 구역에는 폴더별 역할 한 줄과, 문서(`*.md`, README, 명세)마다 상대 경로 링크와 "언제 읽을지" 한 줄을 쓴다. 없는 문서나 추측은 쓰지 않는다. 역할을 알 수 없으면 질문한다.
4. 하위 폴더에 자체 `AGENTS.md`가 이미 있으면 부모 구역에서 그 파일로 링크한다. 새 하위 `AGENTS.md`는 만들지 않는다.
5. 다시 실행해도 같은 링크를 중복하지 않는다. 링크 대상이 실제로 있는지 확인하고, 확인 못 한 점을 보고한다.
